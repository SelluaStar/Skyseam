# Deviations: where the spec or the prompt does not match reality

One entry per external id, API, file or fact that turned out different from `docs/Skyseam-Build-Spec.md` or
the kickoff prompt. Each entry says what was expected, what is real, and what the plan does now. Choices made
where the spec is simply silent go in `DECISIONS.md` instead.
