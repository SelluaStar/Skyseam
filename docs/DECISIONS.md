| K23 | M0 follow-up | Safe arrival (`ArrivalFinder`): the ship's world box plus 1 block of clearance must hold no solid block, fluid or fire. Search up to 24 blocks sideways and 48 vertically from the wanted spot; moving down costs double; refuse the crossing if nothing is clear. The numbers are code constants for now and move into the Seam config in M2 | Author report 3. Prefix sums make each candidate O(1), so even 64³ ships search quickly |
| K24 | M0 follow-up | A crossing reserves its arrival area with a chunk ticket and runs only once every chunk there is entity-ticking (max 5 s, else refused). After arriving, the ship is held still for 3 s with riders pinned to their deck spots, then gets 50% of its old velocity | Author report 1. The M2 Seam charges for 5 s before crossing, which hides the wait |
| K25 | M0 follow-up | State outside a ship's blocks is carried by `PlotMoveListener`s that run between "arrived" and "original removed": Aeronautics balloons (`AeronauticsBridge`) and plot entities (`PlotEntityMover`). | K27 | M0 follow-up | Riders are players, mobs and items on the deck (within 2.5 blocks above the ship's box), players seated on the ship, and anyone the caller brings along (put on a free deck spot near the middle). Riders on foot elsewhere stay behind (spec §6) | Spec §6 edge cases |
| K28 | M1 | **Beat timeline** (spec §6) as constants in `seam/SeamTimeline`, shared by server and client: hairline 0–1.5 s, crack 1.5–3.5 s in 8 steps to 55% open, five thread snaps at 3.1, 3.5, 3.9, 4.3 and 4.7 s (each widens it a notch), interior fades in 5–6 s, stable from 6 s with a ring pulse every 6 s. **Mending plays the reveal backwards at 1.5× speed** (4 s from fully open; a Seam mended mid-reveal mends from where it got to), the closing chime at 75% of the mend, then the scar | The spec gives beat times but no mend length. Reversing the reveal gives "threads re-stitch bottom to top, the crack narrows" for free, because threads snap top first |
| K29 | M1 | Until the Aperture exists (M2), **"someone near" means any non-spectator player** within the hold radius (128). `SeamEntity.keepOpenWhile(...)` is the hook M2's Aperture uses for the ship that opened the Seam | The spec's rule names "qualifying ships", which need the Aperture. A player stand-in lets the author film the Seam now |
| K30 | M1 | Seam size for a ship: **width = the ship's longer horizontal side × 1.5, height = its height × 1.5**, each clamped to 16–64. With no ship near, `/skyseam seam open` makes a 24×20 Seam | Using the longer side means the opening still fits a ship that turns on its approach |
| K31 | M1 | Only one Seam can be open within the entry radius (48), and none opens within 48 blocks of an unfaded scar. **The debug `open` command ignores scars** so takes can be filmed back to back; `/skyseam seam clearscars` clears them | The spec says a scar blocks reopening for 60 s but not how far. The entry radius is the spec's "site" size |
| K32 | M1 | The open Seam's **pull: 0.5 blocks/s² at the Seam, fading to 0 at 60 blocks** (config `pull_strength`, `pull_radius`). A GameTest measured it: a raft 20 blocks away moved 0.58 blocks towards the Seam in 2 s (0.67 expected; air drag takes the rest). The same test showed Sable velocities are in blocks per second | The spec says "a gentle pull" with no number |
| K33 | M1 | Seam sounds play from the server on the **ambient** channel, as fixed-range events heard up to 256 blocks away; how fast each fades with distance is its `attenuation_distance` in `sounds.json` (64–160). The hum is a client loop that follows the Seam | Spec §6: everyone within 256 blocks sees (and hears) the reveal. Sound ranges stay data, so a replacement file needs no code change |
| K34 | M1 | "Clouds part in a ring" (beat 3) is drawn as a soft horizontal ring of light that expands from the Seam, plus a ring of large white puffs pushed outward. Vanilla's clouds are not cut | Cutting the real clouds needs a mixin into cloud rendering, which shader packs replace. Spec §6 asks to stay shader-pack safe |
| K35 | M1 | Thread snaps are **five sound events** (`seam.thread_snap_1`…`_5`) rising C5, D5, E5, G5, A5, played in order. The threads snap top to bottom | Spec §20 counts "thread snap in five pitches" among the Seam's 11 sounds |
| K36 | M1 | The crossing flash (beat 7) is a real-time overlay drawn above the whole HUD (it also shows with F1, because it is part of the scene). Client config `camera_shake` and `screen_flash` (0 to 1) scale the two screen effects | Rule 5 (tunable values are config). A full reduce-motion option is an idea-pool item (§18) |
| K37 | M1 | Debug commands (op level 2): `/skyseam seam open [<pos> [<width> <height>]]`, `seam mend [all]`, `seam list`, `seam clearscars`, `/skyseam ship info`, `ship cross <dimension> [route_a\|route_b]`. **The M0 spike command is gone** (K22): `ship cross` replaces it and adds the flash and whoosh. Forcing a Tide, giving the Almanac and teleporting to landmarks join the tree with those features (M3, M4). The "creative-only command that opens a Seam anywhere" is the same `open` command | Spec §6 lists the debug commands. The others need content that doesn't exist yet |

| K39 | M1 | The Seam entity type is `noSave`. Open Seams and scars live in per-dimension world data (`skyseam_seams.dat`). On server start, every Seam still recorded as open is turned into a scar | Spec §19: "store Seam state in world data and mend on load" |
| K40 | M1 | GameTests can't use NeoForge's mock server player while Simulated is loaded: Simulated sends `simulated:end_sea` when a player joins, and the mock connection refuses it. Seam tests use `keepOpenWhile` in place of a player | Found when the first M1 tests ran |
| K41 | M1 | Tests that measure ship motion run near the End's origin, not at the GameTest structure | GameTests run millions of blocks out, where Sable's physics positions round to half a block |
| K42 | M1 follow-up | **The Seam is a recessed voxel hole, not a flat window.** Open cells sit back from the plane at stepped depths (half-block steps in 4×4 clusters, up to 1.5–4 blocks, on whichever side is away from the camera), with walls down to them. Every surface of the hole, and the sky shards, shows the sky along the camera's ray to one far plane, so it reads as one deep space. Around it: a ragged frame of glowing voxel blocks, stepped cracks branching into the sky (6–18), 16–72 floating voxel fragments (40% hold a piece of the sky), pink and teal colour-split outline ghosts, glitch bursts (a band of rows jumps sideways for 3 ticks), stray voxel holes outside the edge, and sparks and voxel bits shed all round the border. All of it is look only (`client/seam/SeamDecor`), laid out from the Seam's id | Author feedback: "looks a little 2d" and the voxel glitch "should have more spread and have more effects around the border". Reference image 1 has an extruded blocky rim and loose voxel pieces |
| K43 | M1 follow-up | Synthesized sounds are levelled by **loudness** (their loudest 50 ms, RMS) where peak normalising makes them too loud: the hairline at −24 dBFS and the crack at −22 dBFS, as the quietest cues of the reveal. Each sound in `tools/audio/synth.py` has its own random seed, so one recipe can change without touching another file | Author feedback on the loud spawn sound. A short, bright sound normalised to its peak sounds far louder than a long, low one at the same peak |
